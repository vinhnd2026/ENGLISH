Grammar 7 — Conditionals

条件文（Conditionals）：第一条件文・第二条件文・第三条件文・混合条件文・unless / provided / as long as・should・were to

1. 現実的・起こりそうな状況 — 第一条件文（First conditional）

If + 現在形,  will / won't + 動詞の原形

第一条件文（first conditional）は現実的、または起こる可能性のある状況を表します。if の後ろは現在形ですが、指している時間は未来です。結果の節では will / won't が一般的で、going to や can も使えます。

If you fall, I won't be able to catch you!
落ちたら、受け止められないよ！（実際に起こりうる）
If it rains, we're going to get wet.
雨が降れば、私たちは濡れてしまう。（will の代わりに going to）
If the cases are too heavy, I can help you carry them.
スーツケースが重すぎたら、運ぶのを手伝うよ。（結果の節の can）

Unless、provided、as long as

Unless は If … not（〜しなければ／〜でない限り）という意味です。Provided や as long as も条件を導くことができます（〜するなら／〜する限り）。

Unless you leave at once, I'll call the police. (= If you don't leave at once, I'll call the police.)
今すぐ出ていかなければ、警察を呼ぶぞ。
Provided you leave now, you'll catch the train.
今すぐ出発すれば、電車に間に合うよ。

命令文で結果を表す／if の代わりに should

結果の節の代わりに命令文を使うこともよくあります：Get me some cigarettes, and I'll pay you later. また、if の代わりに should を使うと「万が一〜したら」という意味になり、起こる可能性が低く感じられます。

Should you see John, can you give him a message?
もしジョンに会うことがあったら、伝言を伝えてもらえますか。

2. 現実ではない・想像上の現在／未来 — 第二条件文（Second conditional）

If + 過去形,  would + 動詞の原形

第二条件文（second conditional）は現実ではない、想像上の状況を表します。if の後ろは過去形ですが、指している時間は未来です。結果の節では would が一般的で、不確かな場合は might / could も使います。

If you fell, you would hurt yourself.
（もし落ちるようなことがあれば）けがをするだろう。（想像上の状況）
If you became a millionaire, you might be unhappy.
大金持ちになっても、幸せとは限らないかもしれない。（might＝不確かな予測）

were と were to

丁寧な言い方では、すべての人称で was の代わりに were がよく使われます。Were to も第二条件文の表し方の1つです。

If I were taller, I'd join the basketball team. · If I were you, I'd leave now.
背が高ければ、バスケットボール部に入るのに。・私があなたなら、今すぐ出発します。
If they were to offer me the job, I'd turn it down.
もしその仕事を提示されても、断るだろう。

3. 現実ではない過去 — 第三条件文（Third conditional）と混合条件文

If + 過去完了形,  would have + 過去分詞

第三条件文（third conditional）は過去の現実ではない状況を表します。実際に起こったこととは違う過去を想像します。結果の節には might / could もよく使われます。

If John had studied more, he would have got better marks.
ジョンがもっと勉強していたら（実際はしなかった）、もっと良い成績が取れていただろう。
If you had tried harder, you might have succeeded.
もっと努力していたら、成功していたかもしれない。

混合条件文（Mixed conditions）

過去の出来事の結果が現在まで続いている場合は、if 節を第三条件文の形、結果の節を第二条件文の形にできます。

If you had saved some money, you wouldn't be so hard up.
お金を少し貯めていたら、今こんなにお金に困ってはいないだろう。

4. if のその他の使い方

If には when / whenever（〜するたびに）という意味があり、このタイプでは両方の節とも現在形です。If には「〜というのが本当なら」という意味もあります。また、if ＋過去形は、実際に可能性があった、または真実だと分かっている過去の出来事にも使われ、特別な文法ルールはありません。

If/When/Whenever it rains, we play football indoors instead.
雨が降るときはいつも、代わりに室内でサッカーをする。
If you missed the TV programme last night, you can borrow my recording.
昨夜そのテレビ番組を見逃したなら、私の録画を貸してあげるよ。

⭐ Key points — 重要ポイント

  1. 第一条件文の現在形は、現在ではなく未来のことを指します。
  2. 第二条件文の過去形は、過去ではなく未来のことを指します。
  3. 第一条件文と第二条件文の違いは話し手の態度で決まることがあります。起こる可能性が高い→第一条件文、低い・想像上→第二条件文。If she falls, she'll land in the safety net.（本当に落ちる可能性がある）に対して If she fell, she would land in the safety net.（仮定の話）。
  4. 予測が不確かなときは、条件文に might や could がよく使われます。
  5. 混合条件文も可能で、特に過去の出来事の結果が現在に残っている場合に使います：If Brenda hadn't stolen the money, she wouldn't be in prison.
  6. Unless、provided、as long as はいずれも条件を導くことができます。

a-2) If the machine stops, you ______ this button.

c-1) If you ______ me with this exercise, I will do the same for you one day.

c-2) If you help me with this exercise, I ______ do the same for you one day.

e-1) If it ______ fine tomorrow, we will go to the coast.

e-2) If it is fine tomorrow, we ______ to the coast.

f-1) If we ______ a taxi, we will get there before the play starts.

h-1) I don't like this flat. I think I ______ happier if I lived in a house in the country.
