Grammar 13 — Linking Words 1

1. 目的（Purpose）

a) So (that) — 「〜するために」

S + V + so (that) + S + can / could / will / would + V

So that は目的（なぜその行動をするのか）を表します。後ろには通常 can, could, will, would が来ます。

The police locked the door so (that) no-one could get in.
警察は誰も入れないようにドアに鍵をかけた。

b) To — 目的を表す不定詞（Infinitive of purpose）

S + V + to + V  ·  主節と目的の節の主語が同じこと

to + 動詞の原形でも目的を表せますが、主節と目的の節の主語が同一であることが条件です。for to study とは言いません。

Jack went to England to study engineering.
ジャックは工学を学ぶためにイギリスへ行った。

主語が異なる場合は to は使えず、so that が必要です：

Jack went to England so that his brother would have some help working in the restaurant.
ジャックは、弟がレストランの仕事を手伝ってもらえるようにイギリスへ行った。

c) In order to, so as to — 形式ばった言い方

in order to + V · so as to + V · 否定形: in order not to · so as not to
Scientists used only local materials, in order to save money.
科学者たちはお金を節約するために、地元の材料だけを使った。
The soldiers moved at night, so as not to alarm the villagers.
兵士たちは村人を驚かせないように、夜に移動した。

d) For + V-ing — 「〜するためのもの」

For + V-ing は、物が何に使われるか（用途）を表します。

This button is for starting the engine. This is for the lights.
このボタンはエンジンを始動するためのものだ。これはライト用だ。

2. 結果（Result）

a) So … (that) / Such a … (that)

so + 形容詞 / 副詞 (+ that …) · such a + 形容詞 + 単数名詞 (+ that …)
Jim was so tall (that) he hit his head on the ceiling.
ジムは背が高すぎて、天井に頭をぶつけた。
Jim drove so quickly (that) they reached the station twenty minutes early.
ジムがとても速く運転したので、彼らは20分早く駅に着いた。
Helen is such a busy person (that) she never feels bored.
ヘレンはとても忙しい人で、退屈を感じることが決してない。

b) So many / so much / so few / so little

so many / so few + 複数名詞 · so much / so little + 不可算名詞
There were so many passengers (that) we couldn't find a seat.
乗客がとても多くて、席が見つからなかった。
There was so much noise (that) I didn't get to sleep until 3 a.m.
騒音がひどくて、午前3時まで眠れなかった。

c) Too / Not enough + to

too + 形容詞 + to + V（〜すぎて…できない）· not + 形容詞 + enough + to + V（…するほど十分に〜でない）

Too は「必要以上」,not enough は「必要な水準に達しない」を表します。どちらも形容詞 + to と使います：

The bookcase was too big to get down the stairs. The bookcase was not small enough to get down the stairs.
その本棚は大きすぎて階段を下ろせなかった。その本棚は階段を下ろせるほど小さくなかった。

3. 対比（Contrast）

a) Although, though, even though

Although は会話ではよく though になります。Though は文末にも置けますが、although は置けません。Even though は although より対比が強くなります。

Although I asked her, she didn't come. I asked her, but she didn't come, though.
私が誘ったのに、彼女は来なかった。誘ったけれど、彼女は来なかったんだ。
Even though I asked her, she didn't come.
あれほど誘ったのに、彼女は来なかった。（本当に意外だった）

b) While, whereas

形式ばった話し言葉・書き言葉で、2つの事実を比べて違いを強調します。

While United were fast and accurate, City were slow and careless.
ユナイテッドが速くて正確だったのに対し、シティは遅くて不注意だった。

c) However, nevertheless

However は形式ばった文脈で対比を表し、文の最初・途中・最後に置け、コンマで区切ります。Nevertheless はさらに形式ばった表現です。

Normally we don't refund money without a receipt. However, on this occasion I'll do it.
通常、レシートなしでは返金しません。しかし、今回は対応します。
I'm not happy with your work. Nevertheless, I'm going to give you one last chance.
あなたの仕事には満足していません。それでも、最後のチャンスをあげます。

d) Despite と in spite of

despite / in spite of + 名詞または V-ing  ·  節（主語＋動詞）は続かない
In spite of the rain, we went out.
雨にもかかわらず、私たちは出かけた。（＝ Although it was raining, we went out.）
Despite losing, we celebrated.
負けたにもかかわらず、私たちは祝った。（＝ Although we lost, we celebrated.）

⭐ Key points — 重要ポイント

  1. 目的を表す不定詞（to + V）は、主節と同じ主語でなければなりません：I went to the shops to buy some fruit. この用法では for は使いません。
  2. 主語が異なる場合は so that + can/could/will/would を使います。
  3. In order to は to より形式ばっています。通常の会話では to だけで十分です。否定形は in order not to, so as not to。
  4. So + 形容詞/副詞、such a + 形容詞 + 単数名詞、so many/few + 複数名詞、so much/little + 不可算名詞。
  5. Too + 形容詞 + to は「〜すぎて…できない」,not + 形容詞 + enough + to は「…するほど〜でない」。
  6. Despite / in spite of の後ろは名詞または V-ing で、節（主語＋動詞）は続きません。
  7. While, whereas, nevertheless による対比は、形式ばった話し言葉・書き言葉で使います。
