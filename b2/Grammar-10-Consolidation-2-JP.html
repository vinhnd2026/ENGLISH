🔄 さっと復習 — このユニットで扱う4つの分野

この総まとめユニットでは、最近学んだ4つの分野（話法、条件文、wish、受動態）を集めています。下のまとめをさっと読んでから、練習問題で確認しましょう。

a) 話法（Indirect speech / Reported speech）

伝達動詞が過去形（said, told, asked など）の場合、普通は時制を1つ後ろへずらし（時制の一致）、代名詞や時・場所を表す表現も話し手に合わせて変えます。Yes/No疑問文は if/whether を使い、疑問詞のある疑問文は疑問詞を残します。どちらも平叙文の語順にします（倒置しません）。助言・リマインド・命令は advise / remind / tell / ask + 目的語 + to V で、非難は accuse somebody of + V-ing で表します。

He said, 'I am busy.' → He said (that) he was busy.
彼は忙しいと言った。（am → was：時制の後退）
'Did you see anything?' → They asked me if I had seen anything.
彼らは私に何か見たかどうか尋ねた。（Yes/No疑問文は if を使い、平叙文の語順にする）

b) 条件文（Conditionals）

第2条件文： If + 過去形, S + would + V  ·  第3条件文： If + 過去完了形, S + would have + V₃

第2条件文は現在の事実に反すること、第3条件文は過去に起こらなかったことを表します。Unless は if … not と同じ意味です。

If the weather hadn't been so bad, I would have ridden my bike.
天気があんなに悪くなかったら、自転車で行ったのに。（第3条件文）
We won't go out unless the weather is good.
天気が良くなければ、私たちは出かけない。（unless = if … not）

c) wish ・ It's time ・ I'd rather

wish + 過去形（現在） · wish + 過去完了形（過去） · wish + would（変化への希望） · It's time + S + 過去形 · I'd rather + S + 過去形

wish は事実に反する願望や後悔を表します。It's (high) time の後と、他人の行動についての I'd rather の後では、意味は現在でも過去形を使います。

I wish I had known about that.
あのことを知っていたらよかったのに。（wish + 過去完了形：過去への後悔）
It's time we went home. I'd rather you didn't open the window.
もう家に帰る時間だ。窓は開けないでほしい。

d) 受動態（Passives）

be + V₃  ·  It is said that … ↔ S is said to V / to have V₃  ·  have/get + O + V₃

受動態は、行為そのものが行為者より重要なとき、または行為者が不明・言う必要がないときに使います。伝達・思考の動詞（say, think, believe など）には2つの並行する構文があります。have something done は、人に何かをしてもらう（または被害を受ける）ことを表します。

My bike had been stolen. The thieves are thought to have put the bikes in a van.
私の自転車が盗まれていた。泥棒たちは自転車をバンに積んだと考えられている。
We had our house painted last month.
先月、私たちは家にペンキを塗ってもらった。（have something done）

⭐ Key points — 重要ポイント

  1. 話法：伝達動詞が過去形なら時制を後退させます。Yes/No疑問文は if/whether、疑問詞のある疑問文は疑問詞を残し、どちらも平叙文の語順にします。
  2. advise / remind / tell / ask + 目的語 + to V で助言・リマインド・命令を伝え、accuse somebody of + V-ing で非難します。say (that)… と tell somebody (that)… の違いに注意。
  3. 第3条件文は過去の事実に反すること：If + 過去完了形, would have + V₃。unless = if … not。
  4. wish + 過去完了形は過去への後悔、wish + wouldは不満・変化への希望。It's time + 過去形、I'd rather + S + 過去形。
  5. 伝達の受動態：It is thought that… ↔ S is thought to have + V₃（先に起こったこと）。have/get + O + V₃ は人にしてもらうこと。
