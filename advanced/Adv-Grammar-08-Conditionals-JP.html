1. 条件文の基本パターン

a) いつも成り立つこと・習慣 — 現在形＋現在形、過去形＋過去形

if + present, present  ·  if + past, past

条件と結果がいつも成り立つ事実や習慣である場合、両方の節で同じ時制を使います。現在については現在形＋現在形、過去については過去形＋過去形です。

If I work late, I get tired.
遅くまで働くと、疲れてしまう。（いつも成り立つこと）
If the water is boiling, it means the food is nearly ready.
お湯が沸いていれば、料理がほぼできあがったということだ。
We went home early if it was foggy.
霧が出ていると、私たちは早く帰宅した。（過去の習慣）
If it was snowing, we stayed at home.
雪が降っていると、私たちは家にいた。

b) 実際に起こりうる状況 — 現在形＋未来表現

if + present, will / going to / 命令形

結果が本当に起こりうると考えられる場合、主節では未来表現（will、going to）や命令形を使います。

If you keep driving like that, you're going to have an accident.
そんな運転を続けていると、事故を起こすよ。
If you see Mark, tell him I'll ring him tomorrow.
マークに会ったら、明日電話すると伝えて。（命令形）

c) 仮定の状況 — 過去形＋would

if + past simple, would + V

現在や未来についての仮定（現実ではない）の状況では、if節は過去形、主節は would を使います。be動詞は、すべての人称で were が標準形です（日常会話では was も使われます）。一人称では would の代わりに should を使うこともできます。

If I knew the answer, I'd tell you.
答えを知っていれば、あなたに教えるのだが。
If I was having a party, I wouldn't invite Marcia.
パーティーを開くとしても、マーシャは招待しない。
If I left home, I think I should be lonely.
家を出たら、きっと寂しくなると思う。（一人称で should）

d) 過去の仮定 — 過去完了形＋would have

if + past perfect, would have + V3

すでに過ぎた出来事について別の結果を想像する場合、if節は過去完了形、主節は would have を使います。

If I had known you were coming, I would have met you at the station.
あなたが来ると知っていれば、駅まで迎えに行ったのに。

e) 法助動詞（modals）と一緒に

if + present, should / can  ·  if + past, could  ·  if + past perfect, might have

主節には他の法助動詞も使えます。現在の現実的な状況には should / can、仮定の状況には could、過去の仮定には might have を使います。

If you get wet, you should change your clothes immediately.
濡れたら、すぐに着替えたほうがいい。
If you come early, we can discuss the problem together.
早く来れば、一緒にその問題について話し合える。
If I had the money, I could help you.
お金があれば、あなたを助けられるのに。
If you hadn't reminded me, I might have forgotten.
あなたが思い出させてくれなければ、忘れていたかもしれない。

2. if節のバリエーション

a) If only — 仮定を強調する

if の後に only を加えると、仮定の状況が強調されます。過去の出来事については後悔の気持ちも表します。主節は省略されることがよくあります。

If only I had enough time!
時間が十分にあればなあ！
If only I hadn't drunk too much, this wouldn't have happened!
あんなに飲みすぎなければ、こんなことにはならなかったのに！

b) Unless と if の代わりになる表現

unless は「〜でない限り（only if not）」という意味です。一つの状況が別の状況に依存する場合、if は as long as / so long as、provided (that)、only if で置き換えることができます。even if は、条件がどうであれ結果が変わらないことを表します。

I'll go ahead and get the tickets unless you call me this afternoon.
今日の午後に電話がなければ、そのままチケットを買っておく。
I'll do what you say provided the police are not informed.
警察に知らせないという条件で、あなたの言うとおりにする。
Even if it rains, we'll still go for a picnic.
雨が降っても、私たちはピクニックに行く。

c) 過去の条件・現在の結果（混合条件文）

if + past perfect, would + V（have なし）

条件が過去に属していても結果が現在に及ぶ場合、if節の過去完了形と主節の would＋原形を組み合わせます。

If Jim hadn't missed the plane, he would be here by now.
ジムが飛行機に乗り遅れていなければ、今ごろここにいるはずだ。

d) If の後の should・were to・happen to

if の後の should や were to は、出来事の可能性が低いことを示します。happen to は偶然を強調し、should と一緒に使われることがよくあります。

If you should see Ann, could you ask her to call me?
（万が一）アンに会うことがあったら、私に電話するよう伝えてくれる？
If I were to ask you to marry me, what would you say?
もし私がプロポーズしたら、あなたは何と言うだろう？
If you happen to see Helen, could you ask her to call me?
たまたまヘレンに会ったら、私に電話するよう伝えてくれる？
If you should happen to be passing, drop in for a cup of tea.
近くを通ることがあったら、お茶でも飲みに寄って。

e) If it were not for / If it hadn't been for

この2つの形は、一つの出来事が別の人や物事にどう依存しているかを表します。「〜がなければ／〜のおかげでなければ」という意味です。

If it weren't for Jim, this company would be in a mess.
ジムがいなければ、この会社はめちゃくちゃだろう。
If it hadn't been for their goalkeeper, United would have lost.
相手のゴールキーパーがいなければ、ユナイテッドは負けていた。

f) Will と would：丁寧さと強調

if の後の will / would は丁寧な表現になることがあります。また will には「どうしても〜したがる」という強調の意味もあります。

If you will wait here, I'll see if Mrs Green is free.
こちらでお待ちいただけますか。グリーンさんがお手すきかどうか確認します。（丁寧）
If you will stay out late, no wonder you are tired!
どうしても夜遅くまで出歩くのだから、疲れるのも無理はない！（強調）

3. 条件を表すその他の方法

a) Supposing と otherwise

supposing / suppose は主に口語で if の代わりに使えます。otherwise は「そうでなければ」という意味で、文頭にも文末にも置けます。

Supposing you won the football pools, what would you do?
サッカーくじに当たったら、どうする？
Thanks for your directions to the house. We wouldn't have found it otherwise.
家への道を教えてくれてありがとう。そうでなければ、見つけられなかった。

b) But for ＋名詞

but for は改まった表現で if … not の代わりに使え、後には必ず名詞（句）が続きます。

But for your help, we would have been in trouble.
あなたの助けがなければ、私たちは困ったことになっていた。

c) If so / If not

if so（もしそうなら）と if not（もしそうでなければ）は、前の文で述べられた内容全体を受けます。

There is a possibility that Jack will be late. If so, I will take his place.
ジャックが遅れる可能性がある。もしそうなら、私が代わりを務める。

d) 口語での if の省略：命令形＋and

日常会話では、命令形が if節の代わりになることがあります。

Sit down, and I'll make us a cup of tea.
座って。お茶を入れるから。（＝座れば…）

e) If ＋形容詞：be動詞の省略

if it is necessary / possible のような表現では、be動詞を省略できます。

If interested, apply within.
ご興味のある方は、中でお申し込みください。
If necessary, take a taxi.
必要なら、タクシーに乗って。

f) 「〜ではあるが」の if

改まった文では、if が「〜ではあるが（although）」の意味で使われることがあり、通常は if＋形容詞の形です。

The room was well-furnished, if a little badly decorated.
その部屋は家具がよくそろっていたが、装飾は少し下手だった。

⭐ Key points — 重要ポイント

  1. 基本の4パターン：現在形＋現在形（いつも成り立つ）、現在形＋will（現実的）、過去形＋would（仮定）、過去完了形＋would have（過去の仮定）。
  2. 仮定の文では、be動詞はすべての人称で were が標準。一人称では would の代わりに should も使える。
  3. 過去の条件でも結果は現在になりうる：過去完了形＋would（混合条件文）。
  4. unless ＝ if … not。provided (that)、as/so long as、only if も if の代わりになる。even if は「たとえ〜でも」。
  5. if の後の should・were to・happen to は、可能性の低さや偶然を表す。
  6. if it were not for / if it hadn't been for と but for＋名詞は「〜がなければ／〜のおかげでなければ」。
