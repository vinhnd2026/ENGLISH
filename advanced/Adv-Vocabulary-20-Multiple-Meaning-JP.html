1. 句動詞 pull — 1つの動詞、多くの意味

動詞 pull は不変化詞と組み合わさると、意味のまったく異なる句動詞になります。多くの場合、句全体をより硬い単一の動詞に置き換えることができます。

pull away = 発進する · pull a muscle = 筋肉を痛める · pull out = 取り出す / 抜く · pull back = 開ける · pull off = やり遂げる · pull up = 叱る / 止まる

· pull away：車が発進する（started moving）。
· pull a muscle：筋肉を痛める（damaged）。
· pull out a gun：銃を取り出す（produced）；pull out a tooth：歯を抜く（extracted）。
· pull back the curtains：カーテンを開ける（opened）。
· pull it off：難しいことをやり遂げる（succeeded）。
· pull out troops：軍隊を撤退させる（withdrew）。
· pull someone up：人を叱る（told off）。
· pull something along：引きずる（dragged）。
· pull up（車）：止まる（stopped）。

The lorry pulled away very slowly because of its heavy load.
トラックは重い荷物のため、ゆっくりと発進した。（pull away = 発進する）
Mike was pulled up by his boss for making a joke about the Chairman.
マイクは会長について冗談を言ったため、上司に叱られた。（pull up = 叱る）

2. run — 正しい使い方と間違いやすい使い方

run には多くの意味があります。以下には正しくてよく使われる用法もあれば、もっともらしく聞こえてもネイティブが言わない用法もあります。

a) 正しい用法

· run someone to a place：車で人を送る。
· your eyes run：目が潤む、涙が出る（塩素や煙などで）。
· run a train / a service：運行する、サービスを提供する。
· has … to run：（契約などが）まだ有効である。
· run for (the Presidency)：立候補する。

b) よくある間違い

· メッセージを伝える：pass / give を使う — run your message とは言わない。
· 記録に残す：recorded / written を使う — run in our records とは言わない。
· 総額：be を使う — the cost will be 50% higher（run は不可）。
· どうしてもなら：at a pinch / at a push — at a run とは言わない。
· 実のところ：the fact of the matter — the run of the matter とは言わない。

Would you like me to run you to the bus station?
バス停まで車で送りましょうか。（run = 車で送る）
My contract still has six months to run.
私の契約はあと6か月有効だ。（run = まだ有効）

3. 1語で完成する定型表現のセット

定型表現のグループ全体に使える語があります。バラバラに覚えるより、セットで覚える方が身につきます。

panel: an instrument panel · a panel of experts · a control panel · a wooden panel
secret: a secret ballot · a secret agent · keep it a secret · meet in secret · the secret of success
stock: take stock of the situation · out of stock · the stock exchange · the stock market
time: a time sheet · a time zone · only time will tell · long time no see · for the time being
child: a child minder · child abuse · child care facilities · a child prodigy · behaving like a child
They decided to meet in secret.
彼らは秘密裏に会うことにした。（meet in secret）
Only time will tell.
時が経てば分かる。（only time will tell）

4. odd — 奇妙な・不揃いの・たまの

a) 正しい用法

· odd = 奇妙な：odd characters；It's odd to think that…
· odd = 片方だけの、不揃いの：odd socks（左右の違う靴下）。
· the odd … = たまの、時折の：the odd flash of genius。
· the odd one out：グループの中で他と違うもの。

b) よくある間違い

· もう1杯：one more glass — one odd glass とは言わない。
· 互換性がある：compatible with — odd with とは言わない。
· 悪い予感：an ill wind — an odd wind とは言わない。
· 人差し指：index finger — odd finger とは言わない。
· ステップが速すぎる：fast — odd とは言わない。

Look I can't wear odd socks - everyone will laugh at me.
左右の違う靴下は履けないよ。みんなに笑われてしまう。（odd = 不揃いの）
The match was mediocre - apart from the odd flash of genius from Lupeto.
試合は平凡だったが、ルペトのたまの天才的なひらめきは別だった。（the odd = たまの）

5. コロケーションの落とし穴 — 3語のうち合うのは2語だけ

空欄の候補として3語が並ぶことがよくありますが、文の残りと実際に結合するのは2語だけです。残りの1語が「落とし穴」です。

· 領収書を取っておく：retain / keep（maintain は不可）
· じっと立つ：stand / stay still（stop は不可）
· 番組の最終回：final part / programme（series は不可）
· 軽い皮膚の病気：mild / slight（weak は不可）
· 生きる目的：purpose / direction（aim は不可）
· 図々しさ：cheek / nerve（brain は不可）
· 2倍に腫れる：swelled / grew（rose は不可）
· 最後の最後まで：the very / bitter end（far は不可）
· 時間に追われる：pushed / pressed for time（tight は不可）
· あなたの番：your turn / go（take は不可）

Please retain this receipt, as it means we can identify your photographs more quickly.
この領収書は取っておいてください。写真をより早く特定できます。（retain / keep a receipt）
Today's not a good day for a meeting. I'm rather pushed for time.
今日は会議には向かない日だ。かなり時間に追われている。（pushed / pressed for time）

6. 3文すべてに合う1語

1つの語が、3つの文の太字の異なる語すべてに置き換わることがあります。その語に複数の意味があるからです。どの意味かは文脈が教えてくれます。

· take：必要とする（it takes strength）・受け入れる（hard to take）・盗む（take = steal）。
· stretch：十分に挑戦していない（be stretched）・伸びる（the pullover stretched）・伸ばす（stretch out your arm）。
· propose：〜するつもり（propose to leave）・推薦する（propose someone for a post）・提案する（propose setting up a meeting）。
· space：作業する場所・収納スペース・座る場所 — いずれも「空間」。
· moment：しばらくの間（thought for a moment）・時点（from that moment on）・土壇場（at the last moment）。

It would take a lot of strength to lift that boulder.
その大岩を持ち上げるにはかなりの力が必要だろう。（take = 必要とする）
At the last moment, they decided to pull out of the competition.
土壇場で、彼らは大会を棄権することにした。（moment = 時点）

⭐ Key points — 重要ポイント

  1. pull の句動詞は句ごと覚えること。小辞ごとに意味が大きく変わり（pull away、pull off、pull up…）、withdraw、extract、succeed のような単一の動詞に置き換えられるものも多い。
  2. run が正しいのは：車で送る、目が潤む、サービスを運行する、有効期間が残る、立候補する、の各場合。メッセージ・記録・総額には使わない。
  3. panel、secret、stock、time、child のように、定型表現のグループ全体に使える語がある。セットで覚えよう。
  4. odd の主な意味は3つ：奇妙な、不揃いの、たまの（the odd…）。「もう1つの」や「互換性がある」の意味では使わない。
  5. 候補が3語ある場合、実際に結合するのは2語だけのことが多い：retain/keep a receipt、stand/stay still、pushed/pressed for time。
  6. 1つの語が文によって違う意味を持つことがある（take、stretch、propose、space、moment）。文脈で意味を判断しよう。
