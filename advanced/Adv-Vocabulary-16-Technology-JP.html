1. 機器の名前 — 機械とテクノロジーの語彙

contraption · gadget · appliance · equipment · machinery · component · manual · automation · overhaul · experiment

Contraption は用途が分かりにくい奇妙な装置、gadget は小さくて便利な工夫された機器です。Appliance は家庭用電化製品（洗濯機、冷蔵庫など）を指します。

Equipment と machinery はどちらも不可算名詞です。equipment は目的に必要な機器一式、machinery は機械全般、特に大型の産業機械を指します。

Component は機械の部品、manual は取扱説明書、automation は人手の代わりに機械を使うこと、overhaul は全体の点検・修理、experiment は科学の実験です。

What a peculiar contraption! What on earth is that for?
何と奇妙な装置だろう！いったい何に使うのだろう？
A washing-machine is probably the most useful household appliance.
洗濯機はおそらく最も便利な家庭用電化製品だ。
My brother has a shop selling photographic equipment.
兄は写真撮影用の機器を売る店を持っている。

2. 電気の語彙 — コード、プラグ、電源

plug · socket · cable · lead · wire · fuse · mains · live · powered by · run by

Plug（プラグ）は壁の socket（コンセント）に差し込みます。Cable や lead は機器と電源をつなぐコードで、wire はその中の金属線です。

Live は電気が通っているという意味で、とても危険です。Fuse（ヒューズ）は電流が強すぎると切れて回路を遮断します。powered by / run by は何をエネルギー源として動くかを表します。

区別しましょう：motor は電気で動き、engine は燃料を燃やし、machine は機械の総称です。形容詞は electrical（electrical engineer）、名詞は electricity、electrician は電気技師です。

Don't touch that wire! It's live.
その線に触るな！電気が通っている。
This small vacuum cleaner is run by batteries.
この小型掃除機は電池で動く。
The appliance is powered by a small electric motor.
その機器は小型の電動モーターで動いている。

3. 工具とその部品

pliers · spanner · screwdriver · hammer · chisel · grinder · mixer · blender · blade · point · edge · bolt · nut · screw

Pliers（ペンチ）は線をつかんでねじり、spanner（スパナ）は nut（ナット）や bolt（ボルト）を回し、screwdriver（ドライバー）は screw（ねじ）を回します。

台所では：grinder は粉に挽き（コーヒー豆）、mixer は材料を混ぜ、blender は液体状に砕きます。

包丁については：blade は平らな刃の部分、point は鋭い先端、edge は切るための刃先です。

The electrician twisted the wires together using a pair of pliers.
電気技師はペンチを使って線をねじり合わせた。
I can't undo this nut. I need a larger spanner.
このナットが外せない。もっと大きなスパナが必要だ。

4. 技術文書の語形成

INSTALL → installation · MAINTAIN → maintenance · ADJUST → adjustable · ELECTRIC → electrical · APPLY → appliance · CYLINDER → cylindrical · TIGHT → tighten · SAFE → safety · PROTECT → protective · PROCEED → procedure

技術マニュアルには派生語が多く出てきます：-tion / -ance で終わる名詞（installation, maintenance）、-able / -ical / -ive で終わる形容詞（adjustable, cylindrical, protective）。

個別に覚えるペア：tight → tighten（締める）、safe → safety（安全）、proceed → procedure（手順）、そして apply → appliance（目的に「応用される」機器）。

Regular maintenance from a qualified engineer is advised.
資格のある技師による定期的な保守が勧められる。
All engineers must observe all necessary safety precautions.
すべての技師は必要な安全対策をすべて守らなければならない。

5. 問題と解決策 — 「It needs -ing」と決まった表現

It needs oiling / recharging / sharpening / tightening / servicing / painting / adjusting / replacing / winding up / re-programming.

need + -ing は受動の意味を持ちます：It needs oiling ＝「油を差す必要がある」。問題ごとに解決策が決まっています：ドアのきしみ→油を差す、電池切れ→充電する、鉛筆が鈍い→削る、ねじの緩み→締める。

読解文の決まった表現：an aid to convenience（便利さの助け）、the very reason（まさにその理由）、at someone's beck and call（いつでも言いつけに応じる）、on the strict understanding that…（…という明確な約束のもとで）、to the point where…（…という段階まで）、fend for yourself（自分のことは自分でする）。

The battery is dead. It needs recharging.
電池が切れている。充電が必要だ。
Parents lose their freedom and the children lose the ability to fend for themselves.
親は自由を失い、子どもは自分のことを自分でする力を失う。

⭐ Key points — 重要ポイント

  1. Equipment と machinery は不可算名詞。appliance は家庭用電化製品、gadget は小さくて便利な機器、contraption は奇妙な装置。
  2. Plug は socket に差す。live は電気が通っていること、fuse はヒューズ。機器はエネルギー源によって powered by / run by と言う。
  3. Motor は電気、engine は燃料で動く。electrical（形容詞）≠ electrician（電気技師）≠ electricity（電気）。
  4. 工具：pliers はつかんでねじり、spanner はナットやボルトを回し、screwdriver はねじを回す。包丁には blade（刃）、point（先端）、edge（刃先）がある。
  5. 技術文書の語形成：installation, maintenance, adjustable, electrical, appliance, cylindrical, tighten, safety, protective, procedure。
  6. Need + -ing は受動の意味：It needs recharging ＝「充電してもらう必要がある」。問題ごとに解決の動詞が決まっている。
