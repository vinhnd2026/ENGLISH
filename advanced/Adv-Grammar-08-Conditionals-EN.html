1. Basic conditional patterns

a) Always true and habitual — present + present, past + past

if + present, present  ·  if + past, past

When the condition and the result are always true or habitual, both clauses use the same tense: present + present for the present, past + past for the past.

If I work late, I get tired.
(always true)
If the water is boiling, it means the food is nearly ready.
(a present sign and its meaning)
We went home early if it was foggy.
(a past habit)
If it was snowing, we stayed at home.
(a past habit)

b) Real situations — present + future

if + present, will / going to / imperative

When we think the outcome is really possible, the main clause uses a future form (will, going to) or an imperative.

If you keep driving like that, you're going to have an accident.
(going to for a predicted result)
If you see Mark, tell him I'll ring him tomorrow.
(an imperative in the main clause)

c) Hypothetical situations — past + would

if + past simple, would + infinitive

For unreal or imaginary situations in the present or future, the if-clause uses the past simple and the main clause uses would. The verb be normally takes were for all persons in these sentences, although was is heard in everyday speech. In the first person, should can be used instead of would.

If I knew the answer, I'd tell you.
(an imaginary present situation)
If I was having a party, I wouldn't invite Marcia.
(was is possible in speech)
If I left home, I think I should be lonely.
(should instead of would, first person)

d) Hypothetical past — past perfect + would have

if + past perfect, would have + past participle

To imagine a different result for a past event, the if-clause moves back to the past perfect and the main clause uses would have.

If I had known you were coming, I would have met you at the station.
(a past event that did not happen)

e) With modals

if + present, should / can  ·  if + past, could  ·  if + past perfect, might have

Other modals can appear in the main clause: should / can for possible situations in the present, could for hypothetical situations, and might have for hypothetical past situations.

If you get wet, you should change your clothes immediately.
(should — advice)
If you come early, we can discuss the problem together.
(can — a real possibility)
If I had the money, I could help you.
(could — hypothetical)
If you hadn't reminded me, I might have forgotten.
(might have — hypothetical past)

2. Variations of the if-clause

a) If only — adding emphasis

If only adds emphasis to hypothetical situations; with past events it also expresses regret. The main clause is often left out.

If only I had enough time!
(a wish about the present)
If only I hadn't drunk too much, this wouldn't have happened!
(regret about the past)

b) Unless and other alternatives to if

Unless means “only if not”. When one situation depends on another, if can be replaced by as long as / so long as, provided (that) or only if. Even if says that something will happen whatever the condition.

I'll go ahead and get the tickets unless you call me this afternoon.
(unless = if you don't call, I'll buy them)
I'll do what you say provided the police are not informed.
(provided = on condition that)
Even if it rains, we'll still go for a picnic.
(even if — the result does not change)

c) Past condition, present result (mixed conditionals)

if + past perfect, would + infinitive (no have)

When the condition belongs to the past but the result reaches into the present, combine a past perfect if-clause with would + infinitive in the main clause.

If Jim hadn't missed the plane, he would be here by now.
(he missed the plane then; he is not here now)

d) Should, were to and happen to after if

After if, should and were to make an event sound less likely, while happen to emphasises chance and is often used with should.

If you should see Ann, could you ask her to call me?
(should — the speaker does not expect it)
If I were to ask you to marry me, what would you say?
(were to — more hypothetical)
If you happen to see Helen, could you ask her to call me?
(happen to — chance)
If you should happen to be passing, drop in for a cup of tea.
(should + happen to)

e) If it were not for / If it hadn't been for

These forms describe how one event depends on another — roughly “without …” or “if it were not for …”.

If it weren't for Jim, this company would be in a mess.
(present dependence)
If it hadn't been for their goalkeeper, United would have lost.
(past dependence)

f) Will and would: politeness and insistence

Will / would after if can be polite forms; will can also mean “insist on doing”.

If you will wait here, I'll see if Mrs Green is free.
(polite)
If you will stay out late, no wonder you are tired!
(will = insist on staying out)

3. Other ways of making a conditional

a) Supposing and otherwise

Supposing / suppose can replace if, mainly in everyday speech. Otherwise means “or if not” and can go at the beginning or the end of the sentence.

Supposing you won the football pools, what would you do?
(supposing = imagine if)
Thanks for your directions to the house. We wouldn't have found it otherwise.
(otherwise at the end of the sentence)

b) But for + noun

But for can replace if … not in formal language, and it must be followed by a noun phrase.

But for your help, we would have been in trouble.
(but for = if it had not been for)

c) If so / If not

If so and if not refer back to a whole idea that has just been mentioned.

There is a possibility that Jack will be late. If so, I will take his place.
(if so = if he is late)

d) Colloquial omission of if: imperative + and

In everyday speech, an imperative can be used instead of an if-clause.

Sit down, and I'll make us a cup of tea.
(= If you sit down, …)

e) If + adjective: omitting be

In expressions such as if it is necessary / possible, the verb be can be omitted.

If interested, apply within.
(= if you are interested)
If necessary, take a taxi.
(= if it is necessary)

f) If meaning “although”

Formally, if can mean although, usually in the pattern if + adjective.

The room was well-furnished, if a little badly decorated.
(if = although it was)

⭐ Key points

  1. Four basic patterns: present + present (always true / habitual), present + will (real), past + would (hypothetical), past perfect + would have (hypothetical past).
  2. In hypothetical sentences, be is usually were for all persons; the first person can use should instead of would.
  3. A past condition can have a present result: past perfect + would (a mixed conditional).
  4. Unless = if … not; provided (that), as/so long as and only if can also replace if; even if = “whatever happens”.
  5. Should, were to and happen to after if make the event sound unlikely or a matter of chance.
  6. If it were not for / if it hadn't been for and but for + noun = “without … / if it were not for …”.
